# Phase 2 — Provider-compatible booking links (Nov 2, 2026)

## Reproduced production evidence
New genuine post-release outbound records across WhatsApp, Instagram, Messenger and Telegram contained text like `[Complete Your Booking](https://www.ishinaillab.com/?ishi_booking_slot=...)`. The original AI Engine bot generates Markdown links, but the actual Ishikeit adapters send provider **text** payloads, not Markdown entities. `src/channels/telegram-send.ts` uses Telegram Bot API `sendMessage({text})` with no `parse_mode` or `entities`; Meta adapters send ordinary `message.text` and WhatsApp `text.body`. This means a textual Markdown link is not guaranteed to be rendered as an inline clickable label. The studio-facing booking URL should remain an explicit readable URL so it is easier to open in messaging apps.

## Minimal fix
`src/processing/explicit-links.ts` recognizes inline HTTP(S) Markdown `[label](URL)` and converts it to `label: URL` without modifying any URL byte. `MessageReceivedHandler` applies the presentation transformation to AI text parts **before** Meta's validated length-aware splitter and durable outbox action creation. It applies to Telegram direct and connected-account text messages as well as Messenger, Instagram, WhatsApp and eventual TikTok; non-text media and plain/raw URLs remain unchanged. The sender modules and their parse_mode/consent/window/retry controls are untouched. No customer messages are generated by tests.

Official sources:
- Meta WhatsApp Cloud API sends a text object with `body` and optional `preview_url`: https://developers.facebook.com/documentation/business-messaging/whatsapp/reference/whatsapp-business-phone-number/message-api
- Meta Messenger Send API uses `message.text`: https://developers.facebook.com/documentation/business-messaging/messenger-platform/send-messages
- Instagram API Send Messages uses `message.text`: https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/messaging-api
- Telegram Bot API `sendMessage` only parses Markdown/HTML when `parse_mode` or `entities` supplied: https://core.telegram.org/bots/api#sendmessage
